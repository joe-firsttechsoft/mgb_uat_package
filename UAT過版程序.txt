=== 過版清單整理 ===

1. 看 SIT 是否進 UAT（只列出已經進UAT的, "-"號已進, "+"號未進）
	cmd(final-輸出內容還沒有到UAT的), 包含commit, author, date, commit message
		git cherry -v FEP_1-2_UAT FEP_1-2_SIT | grep '^+' | awk '{print $2}' | xargs -I {} git show -s --format="%h%x09%an%x09%ad%x09%s" --date=short {}

	cmd: git cherry -v FEP_1-2_UAT FEP_1-2_SIT | grep '-'    (SIT 上的 commit，其內容已經存在於 UAT, 包含：cherry-pick 過去的, rebase 過的, patch 剛好一樣的, 不只限於 cherry-pick)還
	cmd: git cherry -v FEP_1-2_UAT FEP_1-2_SIT | grep '^+'    (還沒過版到UAT的, git cherry 比的是「內容」，不是「歷史」)
	cmd: git log FEP_1-2_UAT..FEP_1-2_SIT --oneline	(顯示「在 sit 上，但不在 uat 上」的 commit)
        cmd: git log FEP_1-2_UAT..FEP_1-2_SIT --pretty=format:"%h %an %ad %s" --date=short  (可能會不包含cherry-pick, rebase, squash merge)
2. 匯入excel篩選出未進的, 依據commit message比對 UAT 去找出對應的 commit
3. 依據SIT的commit查找過版清單(線上), 填入UAT commit id, 並且更新過版日期
4. Git Branch 打 tag 紀錄
